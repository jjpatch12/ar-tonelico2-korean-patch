## 반드시 확인할 기준 ISO

파일명이 아니라 **SHA-256**으로 적용 가능 여부를 확인하세요. 작업에 사용한 파일 이름에는 `Japan1`이 있지만, 실제 대상은 **SLUS-21788 영문 기반 프로젝트 기준 ISO**입니다. 일반 일본판이나 다른 영문판·재번역판·이미 한국어화된 ISO에 대한 호환성을 의미하지 않습니다.

| 구분 | 크기 | SHA-256 |
| --- | ---: | --- |
| 패치 전 기준 ISO | 4,308,598,784 바이트 | `2f6bf168b6dc46b49b9d806c8c3c9824424daccff659d1414855c31c131dd489` |
| 패치 후 한국어 ISO | 4,321,628,160 바이트 | `af5f75a2a9e81c4d61856558d5c1611f8f82487cd7179af651b6af4146e3ea99` |

PowerShell에서 확인:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\원본.iso'
```

기준 해시가 다르면 적용을 중단하세요. 체크섬 검사를 강제로 끄거나 이미 한국어화된 ISO에 덧씌우지 마세요.

### 작업 집계 참고

- 기본 대사 패키지: **52,956개 EVD/ERX 행**(EVD 43,246 / ERX 9,710).
- 실행 파일 기반 UI 텍스트: 당시 적용 집계 **7,878건**.
- UI 이미지: 당시 완료 집계 **711개 컨테이너**(RPK 625 / FP 86).
- 이후 누락 선택지·공통 응답·도감·시마법·화자명·UI 표시 오류 수정까지 이번 패치에 합쳤습니다.

위 수치는 서로 다른 단계의 작업 기록입니다. 후속 수정에는 중복 항목이 있으므로 단순 합산한 “전체 번역 문장 수”나 게임 전체 번역률로 해석하지 마세요.

## 적용 방법

준비물: 위 해시와 일치하는 본인 소유의 기준 ISO, 이번 `.xdelta` 파일, xdelta3 또는 xdeltaUI, 충분한 여유 공간.

1. PCSX2를 완전히 종료합니다.
2. 기준 ISO의 SHA-256을 확인합니다.
3. 릴리스에서 `ArTonelico2_Korean_v0.3.0.xdelta`와 `SHA256SUMS.txt`를 내려받습니다.
4. 패치 파일도 SHA-256을 확인해 `SHA256SUMS.txt`와 비교합니다.
5. 아래 방법 중 하나로 패치를 적용합니다. 출력은 **원본과 다른 새 파일 이름**을 사용해 기준 원본을 보존하세요.
6. 출력 ISO의 SHA-256이 위 “패치 후 한국어 ISO” 값과 정확히 같은지 확인합니다.
7. PCSX2에서 출력 ISO를 선택하고 게임을 새로 부팅합니다. 이전 패치의 실행 메모리가 담긴 세이브스테이트 대신 메모리 카드 저장 데이터를 불러오는 것을 권장합니다.

### xdeltaUI

- `Apply Patch` 탭
- `Patch`: `ArTonelico2_Korean_v0.3.0.xdelta`
- `Source File`: 해시가 일치하는 기준 ISO
- `Output File`: 원본과 다른 출력 파일명
- 적용 후 반드시 출력 ISO 해시 확인

### 명령줄 xdelta3

공식 배포처: [jmacd/xdelta Releases](https://github.com/jmacd/xdelta/releases)

아래는 파일들이 같은 폴더에 있을 때의 PowerShell 예시입니다.

```powershell
.\xdelta3.exe -d -s '.\원본.iso' '.\ArTonelico2_Korean_v0.3.0.xdelta' '.\ArTonelico2_Korean.iso'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\ArTonelico2_Korean.iso'
```

검증된 디코더는 xdelta3 **3.2.0** 및 **3.1.0**입니다. 이 패치에는 추가 외부 압축 해제나 이전 버전 패치가 필요하지 않습니다.

## 확인한 사항과 남아 있는 한계

- xdelta 복원 결과가 현재 한국어화 ISO와 **전체 바이트 기준 SHA-256 및 크기 일치**하는지 검증했습니다. 자세한 결과는 `release-manifest.json`에 기록합니다.
- ISO 내부 파일 247개를 대조했으며 변경 파일은 12개입니다. 나머지 235개 파일의 내용은 동일합니다. 한 개의 리소스 묶음 안에 많은 텍스트·이미지가 들어 있으므로, 12개는 번역된 개별 리소스 수가 아닙니다.
- 일부 화면은 사용자 확인을 거쳤지만 **전체 루트·엔딩·모든 메뉴와 영상의 실기/에뮬레이터 완주 검증을 마친 상태는 아닙니다.** 그래서 이번 배포를 통합 테스트판으로 표시합니다.
- 영상 전체를 새로 번역한 것은 아닙니다. 일본어가 영상에 직접 그려진 연출 문자, 로고·크레디트 등은 남아 있습니다.
- 별도 오프닝 파일 **`AT2_OP1D.SFD`는 변경하지 않았습니다.** 이 파일을 사용하는 재생 경로에서는 기존 자막이 나올 수 있으며, 해당 경로는 별도 확인이 필요합니다.
- 로고·고유 표기·버튼 기호·숫자·일부 약어와 테스트/비사용 문자열 등은 원문을 유지한 항목이 있습니다. 미발견 누락 가능성도 남아 있습니다.
- UI 선명도 보정은 게임 원래 텍스처 규격 안에서 이루어졌습니다. 전면적인 HD 텍스처 팩이 아니며, 확대 해상도와 필터 설정에 따른 차이가 있을 수 있습니다.
- 글꼴 종류를 새로 바꾸는 패치가 아닙니다. 기존 한국어화에 사용한 **Noto Sans KR Medium 500**을 유지하고 누적 반영합니다.

## 문제 제보

화면 캡처, 발생 장소·상황, PCSX2 버전, 출력 ISO SHA-256, 메모리 카드 저장으로 재현되는지 여부를 함께 남겨 주세요. ISO 전체나 개인 정보가 담긴 파일은 업로드하지 마세요.

이 패치는 비공식 한국어화 작업물이며 원 게임 제작사·배급사 및 글꼴 제작자의 공식 배포 또는 보증을 의미하지 않습니다.
